# 茶与金平糖听歌站界面改版

## 最终行为

站点使用茶与金平糖汉化组身份。大厅第一屏可以加入常驻电台，房间列表支持分类和搜索；创建房间、帮助和昵称使用弹窗。桌面房间同时展示队列、封面与歌词、聊天，手机通过标签切换面板，固定播放条持续可用。

主视觉为 minusT 的《天空璋レイマリ》（Pixiv 65515001），从用户提供素材包中选取。房间卡片显示正在播放的专辑封面，缺图时使用中性的音乐图标。已移除随机分配的三张插画及旧宣传文案。

Go 后端业务逻辑保持原样，只更新站点名称及演示数据中的旧品牌。前端使用现有 HTTP / WebSocket 契约。清空待播保留当前歌曲，与后端行为一致；切最后一首时重播当前歌曲，也保留后端原语义。

## 联调修复

- 搜索使用后端当前音乐源，避免演示模式仍请求 wy。
- 昵称修改后用新昵称重新连接当前房间。
- 密码房的口令错误进入密码输入流程；创建后的密码放在 history state 中，分享地址不包含密码。
- 空格快捷键不拦截按钮、链接、输入框和弹窗中的操作。
- 音量零值可保存；恢复收听时重新对齐房间；同一首歌曲重播可回到开头。
- 弹窗支持焦点循环、Escape 及关闭后恢复焦点；聊天浏览历史时不强制滚到底部，提供新消息按钮。
- 构建复制脚本使用可移植的文件读写，解决本机 Windows 原生 cpSync 的访问错误。
